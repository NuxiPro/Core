# Contributing to NuxiPro

Thank you for your interest in contributing to NuxiPro.  
Before submitting any contribution, please read this document carefully.

---

## Contributor License Agreement (CLA)

Before contributing, you must read and accept the [Contributor License Agreement](./CLA.md).
PRs cannot be merged without an explicit CLA signature (checkbox + signature comment, see [CLA.md](./CLA.md#how-to-sign)).

---

## How to Contribute

### Reporting a Bug

Open an issue with:
- A clear description of the problem
- Steps to reproduce
- Expected vs actual behavior
- Your environment (OS, browser, Node version, etc.)

### Suggesting a Feature

Open an issue tagged `enhancement` with:
- A description of the feature and the problem it solves
- Any relevant context or mockups

### Submitting a Pull Request

1. Fork the repository
2. Create a branch from `main`: `git checkout -b feat/your-feature`
3. Make your changes
4. Ensure your code follows the existing style and conventions
5. Open a Pull Request with a clear description of what you changed and why
6. Sign the CLA: check the CLA box in the PR template and post exactly this comment on your PR: `I have read the CLA Document and I hereby sign the CLA`

> PRs cannot be merged without an explicit CLA signature (checkbox + signature comment).

---

## Code Style

- Follow the conventions already present in the codebase
- No commented-out dead code in final PRs
- Keep commits atomic and descriptive

---

## Questions

If you have any questions before contributing, open an issue or contact the maintainer directly.
